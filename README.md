# web

The GRMPY website, served at grmpy.uk. It is a static site (HTML, CSS, JS). It is currently a coming-soon page.

## Hosting

- GitHub Pages serves the site from `main` of grumpytinkerers/web, with the custom domain set in `CNAME`.
- Flow: changes land on Gitea `dvdcmrn/web` first (by pull request), then the mirror pushes `main` to GitHub `grumpytinkerers/web` (fast-forward only, never forced).
- Do not remove or edit `CNAME` without a matching DNS and Pages change.
